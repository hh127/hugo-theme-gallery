# 相册管理台（本地 Web 界面）

> **这一份是随主题一起发布的副本**（位于 `themes/<主题>/tools/admin/`），主题仓库自带界面，克隆主题就能用。
> 启动后服务会**自己向上找到站点根目录**（含 `hugo.toml`/`config.*` 且有 `content/` 的那一层），
> 所以放在主题里也能直接管理正在开发的站点；也可以用 `--root <目录>` 显式指定站点根目录。
> 如果你在站点自己仓库里也放了一份 `tools/admin/`，两者是同一套代码，按需保留一份即可（下面的路径按本文档所在位置理解）。

一个**零依赖**的本地管理软件，把原来要在命令行里敲的操作变成点按钮：管理相册与图片、写游记、改页面、构建、发布。
只监听 `127.0.0.1`，不会对公网开放；不修改主题源码，只读写 `content/`、`data/` 和 `public/`。

## 启动与关闭

**启动**：双击本目录下的 **`start.bat`** —— 命令行窗口会保持打开，浏览器自动弹出管理页面。
也可以在自己的终端里跑：

```bash
node themes/<主题>/tools/admin/server.mjs            # 默认 http://127.0.0.1:7788
node tools/admin/server.mjs --port 8899 --no-open    # 装在站点仓库里时
node tools/admin/server.mjs --root D:/path/to/site   # 显式指定站点根目录
```

**关闭**：双击本目录下的 **`stop.bat`**（会连它启动的 `hugo server` 预览子进程一起关掉）；
或者在那个命令行窗口里按 `Ctrl+C`。

细节：

- 服务的进程号写在管理台目录下的 `.admin.pid`，`stop.bat` 优先按它精确关闭，找不到时再扫描命令行兜底；两个脚本都是双击可用，中文提示写在本文档里（`.bat`/`.ps1` 内部保持 ASCII，避免 cmd 用系统代码页解析非 ASCII 时把命令拆坏）。
- 站点根目录默认自动查找，找不到时会退回本文件的上两级目录；不确定时用 `--root` 指定。
- 重复双击 `start.bat` 不会报错：检测到端口已被占用时，会提示「管理台已经在运行」并直接把页面打开，不会起第二个实例。
- 关掉命令行窗口（或 `stop.bat`）后网页会显示「无法连接」，属正常现象。

## 界面能做什么

| 标签页 | 能做的事 |
| --- | --- |
| **概览** | 相册/图片/体积/游记总数；工具链检测（hugo、node、git、python、exiftool）；待提交文件；站点配置摘要；风险提示（弱口令、原图体积、失效元数据）；右上角可切换**暗色/亮色主题**（会记住选择） |
| **相册** | 新建/删除相册；改标题、描述、封面、`featured`、`private`、密码；拖拽上传图片（支持多选）；拖拽排序（自动重命名成 `01-`、`02-` 前缀）；单图编辑标题/描述/相机/镜头/ISO/光圈/快门/焦距/日期、隐藏、设为封面、重命名、删除 |
| **游记** | 新建/删除游记；编辑标题、日期、摘要、封面（`cover_from` + `cover`）；Markdown 正文 + 短代码；一键插入 `{{< photo >}}` 短代码（下拉选相册和图片，不用手敲文件名）；**右侧实时预览**（自动同步滚动） |
| **页面** | 编辑 `content/*.md` 单页（首页、关于、收藏等）的标题、描述、正文；**右侧实时预览** |
| **构建** | 一键构建（EXIF → `hugo --gc --minify` → 加密受保护相册，与 CI 同流程）；单独提取 EXIF / 单独加密；启动/停止 `hugo server` 本地预览并内嵌显示；打开 `public/` 与仓库目录 |
| **发布** | 查看改动文件、勾选要提交的内容、填提交说明、`提交` 或 `提交并推送`（推送后 GitHub Actions 自动发布到 gh-pages）；查看实时日志 |

右侧「任务输出」面板会实时显示命令输出，长任务可以中途停止。

## 实时预览（游记 / 页面）

编辑正文时，右侧会**边打边渲染**，不用先保存、也不依赖 `hugo server`：

- 展开 `{{< photo src="…" from="…" caption="…" >}}` 短代码，直接从相册里取图显示（走 `/api/media`），图片找不到会显示黄色告警而不是空白；
- 支持标题、段落、引用、列表、代码块、粗体/斜体/删除线、链接、图片，以及行内 Markdown；
- **双向同步滚动**：滚动编辑框会带动预览，滚动预览也会带动编辑框（程序性滚动不会互相打架）；
- 预览栏宽（≥1180px）时是**独立一列**，窄屏时自动折到编辑框下面；
- 想确认真实效果（主题的排版、灯箱、加密等），点右上角「在站点预览中打开」：它会确保 `hugo server` 已启动，然后直接打开对应页面（游记 → `/stories/<slug>/`，单页 → 对应路径）。

预览是**简化渲染**，以站点构建结果为准；模板里那些 Hugo 特有能力（`related`、图片处理、加密）不会在这里体现。

## 云端图片（CDN 直链）

相册里除了本地文件，还支持直接引用**已经在 CDN/图床上的图片**（主题的 `remote_images` 功能）。在「相册」页的**云端图片**卡片里粘贴直链即可加入：
仓库里不存图片文件，访客浏览器直接向 CDN 取图，缩略图链接会自动加上 `params.gallery.cdnResize` 后缀（阿里云 OSS 风格）。

需要注意（都是主题的既有行为，不是管理台的限制）：

- **一条抓不到的链接会让整站构建失败**。主题在 `gallery.html:115` 直接调用 `resources.GetRemote`，没有兜底；所以管理台会在添加时校验链接，并提供「验证链接」按钮批量体检（容量只有前 2KB）。
- **不能用 `localhost` 和 IP 直链**：Hugo 默认安全策略 `security.http.urls` 禁止抓取 `localhost`、IP 地址和带账号密码的 URL，管理台会直接拒绝。
- 云端图**不支持「隐藏 / 设为封面」**（主题只对本地文件生效），卡片封面固定取第一张。
- 一个相册**不要混用**本地图和云端图：只要 `remote_images` 非空，相册卡片的封面和张数就只统计云端图（管理台会给出告警）。
- 「下载到本地相册」按钮可以把云端图抓回 `content/<相册>/`，并从 `remote_images` 移除、把元数据 key 换成文件名，适合想长期保存的图。

## 和主题数据模型的对应关系（避免踩坑）

- 相册 = `content/<目录>/index.md` + 目录里的图片文件（Hugo page bundle）。
- **图片顺序由文件名决定**（`01-`、`02-` 前缀），front matter 里的 `weight`/`title` 不改变顺序——所以「应用排序」实际是重命名文件，管理台会同时改掉 `images:`/`resources:` 里的 `src`，保持一致。
- 单图元数据写在 front matter 的 `images:` 列表（按文件名索引；**云端图的 key 就是那条 URL**），显示开关（`hidden`/`cover`）写在 `resources:` 列表的 `params` 里，管理台会自动维护这两处。
- **密码保护只是把相册页面的图片列表加密**（构建时由 `themes/gallery/scripts/encrypt-protected.mjs` 处理），原图文件仍然可以被直接下载。重要照片不要只靠密码。
- 相册加了 `password` **不会**自动 `noindex`、也不会从 sitemap/RSS 里排除（要额外加 `private: true`）。
- 图片的相机参数来自 `data/exif.json`（`scripts/extract-exif.py` 生成，**需要装 exiftool**）；没装 exiftool 时构建会跳过 EXIF 提取，界面会显示 ✗。

## 安全性

- 服务只绑定 `127.0.0.1`，没有登录，**不要把这个端口暴露到公网**。
- 删除操作不直接删文件：相册/图片/游记会移动到仓库根的 `.admin-trash/<时间戳>/`（已在 `.gitignore` 中忽略），确认无误后可手工清空。
- 路径做了越界校验，写文件仅限 `content/` 下的 Markdown 和相册图片。

## 常见问题

- **想换端口**：`node tools/admin/server.mjs --port 8899`。端口被占用时 `start.bat` 会提示「已经在运行」并打开页面，而不是报错退出。
- **关不掉 / 想确认是否关了**：双击 `stop.bat`，它会打印被关闭的进程号；网页显示「无法连接」就说明确实停了。
- **提示找不到 hugo**：安装 Hugo extended（≥ 0.123），并确保 `hugo` 在 PATH 里；或放到 `C:\Users\<你>\AppData\Local\Microsoft\WinGet\Links\`。
- **预览窗口一片空白**：`hugo server` 需要几秒启动，等状态变成「运行中」再刷新（管理台会自动等端口就绪，国内网络下 hugo 绑定的是 IPv4，页面统一用 `127.0.0.1` 而不是 `localhost`）。
- **云端图添加后构建报 `is not whitelisted in policy "security.http.urls"`**：链接是 IP 直链或 `localhost`，换成域名即可（管理台已在添加时拦截）。
- **构建后网站没变化**：确认切到「发布」推送到 GitHub，等 Actions 跑完（1–2 分钟）。
- **改完 `.bat`/`.ps1` 后双击报奇怪的命令错误**：这两个脚本内部必须保持 ASCII（中文注释会让 `cmd`/PowerShell 5.1 按系统代码页解析失败）；要加中文说明请写在这个 README 里。
